8. AI: BACKGROUND FIRST, USER-TRIGGERED ONLY WITH CAPS
------------------------------------------------------
Rule: AI runs from scheduled jobs (cron, Message Batches at half price) with a hard limit on how
much each processes; pages show what is already written. AI a user can trigger (a button, a chat)
is allowed only behind caps (8.9) so visitors can never empty the credits: per user per day, per
feature per day for the whole site, and the Console's monthly spend limit (Billing -> Limits) as
the last safety net. Claude Haiku 5.5 by default. HARD LIMIT: US$5 a month for all Claude use,
background jobs included (the Console's limit set to US$5 too), apart from the one-time first
tagging of the catalog (7.10).
TMDB first: whatever TMDB has (free, already synced: genres, keywords, overviews, episode
summaries, age ratings, credits, translations, images) is taken from TMDB; Claude only adds what
TMDB doesn't have (moods, themes, pacing, recaps, names for groups of titles) or fills a gap TMDB
leaves (a missing translation), and is told the TMDB data, never asked to guess it.
