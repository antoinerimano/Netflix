1. ESSENTIALS USERS EXPECT
--------------------------
[x] 1.1 Continue watching
        "Continue watching" row first on the home page (last movie / episode opened per show),
        click resumes at that episode, X to remove it from the row,
        "Next episode" button on the watch page.
[x] 1.1b Real watch progress
        Minutes watched from the players' postMessage events (videasy PLAYER_EVENT,
        cinesrc:*, vidcore:*): progress bar on cards, drop finished movies from the row.

[x] 1.2 Kids profiles that really filter
        Import TMDB certifications + "adult" flag in the sync scripts, apply the profile's
        age_restriction to every home row, search, browse pages and the watch page.
        Add a real "Kids" profile option.

[x] 1.3 My List saved on the server
        Today it lives in the browser (localStorage): lost when changing device or clearing data.
        Store it in the DB, sync across devices, better signal for recommendations.

[x] 1.4 Like / Dislike / Not interested buttons
        The backend already accepts these actions; add the buttons (cards + detail page)
        and use them: hide "not interested", lower similar titles after a dislike.

5. LANGUAGES
------------
[x] 5.1 The app in the user's language: English, French, Spanish, German, Italian, Japanese, Chinese,
        Hindi, Portuguese (Brazil), Russian, Bengali, Arabic, Urdu (right to left: 7.9)
        Frontend: i18next / react-i18next, one JSON file per language and area (src/i18n/locales),
        English bundled and every other language downloaded on first use (its own chunks), CLDR
        plurals, numbers / dates / durations / language and country names through Intl, <html
        lang> + page title follow the language, `npm run i18n:check` (same keys, plural forms and
        placeholders in every language; keys used in the code exist).
        Language = the active profile's language (profile form), else the picker on signed-out
        pages / footer, else the browser's. The API gets it as Accept-Language.
        Backend: LocaleMiddleware + gettext (locale/<lang>/django.po): API messages (with stable
        codes), password reset / email change / new episode emails (in the profile's language).
        Catalog: TitleTranslation / EpisodeTranslation from TMDB (sync_tmdb_translations, in the
        3-hourly cron), swapped into every API response by the JSON renderer (users/localize.py);
        search also matches translated names. Home rows / "why" lines / search reasons are sent
        as data and worded by the app. Profiles saved as "jp" became "ja".

7. GROWTH: PERSONAL FROM DAY ONE, REASONS TO COME BACK
------------------------------------------------------
[x] 7.1 Taste onboarding ("What do you like to watch?", /taste)
        After creating a profile (sign up step 2, or "Add" on Who's watching?): 60 well-known titles
        (300+ votes, a poster, within the profile's age limit, spread over genres, movies and shows
        alternating, 12 in the profile's language), pick 3 or more, Skip always there. Picks are
        saved as likes (TitleRating, TitleAction provider "onboarding") and the home snapshot is
        rebuilt on the spot, so the first home page is already personal. Home: "Make this home page
        yours" banner while a profile has no like / list / play yet (needs_taste), closable.
        Backend: reco/taste.py (GET / POST /api/taste/).
[x] 7.2 Import your history (/import, account page, link on the taste picker)
        Letterboxd (.zip or .csv) and IMDb (ratings / watchlist .csv) export files, from a phone or
        computer (a TV says so; Trakt was built then left out: too few users). High ratings + hearts ->
        likes, low -> dislikes, watched -> TitleAction "watched" (new, weight 3, seeds "Because you
        watched"), watchlist -> My List; dates kept; never overrides what was done in the app; matched
        by IMDb id, else name + year. Home rebuilt after (never replaced by an empty one).
        Backend: reco/imports.py.
[x] 7.2b Account page: profiles are managed in one place ("Manage profiles", /profiles?manage); the
        account page only links there ("Profiles · 3 of 4").
[x] 7.2c Focus never covers a neighbour (TV remote): buttons / chips / pills get a ring without
        growing (scale ate the 8-12px gaps), profile pictures and colors a thinner halo; measured on
        every page, sheet and dialog by e2e/tests/focus-overlap.spec.js (2px clear at least).
[x] 7.3 Upcoming (/calendar, navbar "Upcoming", 5th tab on phones, button in the notifications panel)
        New episodes of the profile's shows (followed, in My List, watched in the last 6 months) day by
        day for 30 days (Today / Tomorrow / date, "In N days"), the past week's in their own row;
        out today -> the player on that episode, still to come -> the show. "Coming back soon": popular
        shows with an episode coming, OK follows them and their episodes join the calendar. Remote:
        one row per day (group), the focus stays on a followed suggestion. The episode sync
        (sync_tmdb_daily_episodes) now also refreshes every tracked show still on air (--no-tracked
        turns it off), so a show off TMDb's airing / trending lists keeps its dates.
        Backend: reco/calendar.py (GET /api/calendar/).
[x] 7.4 Watch history (/history, profile menu "Watch history")
        WatchEvent: one entry per movie / episode per day, written when the watch page opens; the
        first history is built from Continue watching + Play presses (migration). By day, newest first,
        50 per page. Remove an entry (the title's last one also clears Continue watching, Play / open
        signals, its sources and its "Because you watched" row; likes / My List stay), Clear history
        (confirmed), Pause (Profile.history_paused: no entry, progress, Play / open signal, impression
        or source result is saved), Download (.csv). Remote: rows, Right = remove, the focus moves
        to the next entry. Backend: reco/history.py.
[x] 7.5 Your year (/stats, profile menu "Your year in review", "Your year" on the history page)
        From the watch history: about N hours (runtimes: movie, episode, else the show's usual length),
        titles / movies / shows / episodes / days, longest + current streak, first title of the year,
        minutes per month (bar chart, one series in the brand red, validated on the card surface;
        value on the busiest month, hover tooltip, table for screen readers), genres (time split
        between a title's genres, bars scaled to the top one), most watched, actors you kept watching
        (5 first-billed), years to switch. "Share my year": a 1080x1350 picture (share sheet, else
        saved). Remote: every section takes the focus; Share under its text (at the right edge Down
        skipped it). Navigation fix: Back to a page still loading no longer sends the focus to the
        footer (recoverFocus waits for restorePlace). Backend: reco/stats.py.
[x] 7.6 Franchises in watch order (/collection/:id)
        TMDB collections (Title.collection_id, indexed, kept in sync by Title.save(), backfilled):
        movie pages "Part of <collection>" (numbered row, this one marked, watched checked, "Watch
        order" as its last tile), the collection page (progress, "Start with" / "Watch next", parts in
        release order, "Coming soon" for announced ones), "Next movie" in the player, home row "Next

        Remote: the link is the row's last tile (above the row, Up from the other movies missed it).
        Navigation fix: OK on a link no longer sends the new page's focus to the footer while it

        reco/collections.py.
[x] 7.7 Lists you make and share (/lists/:id, shared at /l/:shareId)
        Named lists per profile (50 max, 500 titles each): "Add to a list" in the options sheet (hold
        OK) and beside My List on title pages (a new list starts with the title); "Your lists" at the
        top of My List; a list's page (titles with remove, Edit, Delete confirmed, Share switch: the
        address in big letters to type on a phone, the share sheet / Copy). Shared page for anyone
        (signed out too): name, "A list by <profile>", posters; "Save a copy" signed in. Django serves

[x] 7.8 What to watch? (/pick, "Surprise me" on the home banner)
        The time you have (under 90 min, about 2 h, one episode, no limit) and a mood (funny, exciting,
        scary, feel-good, thoughtful, romantic: genres in / out), then "Show me" (6 titles with their
        length, a new set each time) or "Surprise me" (one, big: Watch / More info / Another one).
        Well-liked, released, within the age limit, not watched / rated / turned down; ranked like the
        home page then drawn among the best 60, the best more often. Candidates cached an hour per
        age limit + time + mood (15 ms warm). Remote: choice rows are groups, the focus follows the
        results, "Another one" keeps it. Backend: reco/pick.py.
[x] 7.9 Arabic and Urdu (right-to-left layouts)
        The app, the titles (TMDB ar-SA / ur-PK) and the server's emails and pages in Arabic and Urdu;
        <html dir="rtl"> (app and the server-rendered page shell). The CSS uses logical properties
        (margin-inline-start, inset-inline-end, text-align: start...) so the layout flips by itself;
        src/i18n/rtl.css holds the rest: arrows mirrored, banner shades on the right. The poster rows
        are mirrored as a whole (react-slick's own rtl mode misplaces short rows), cards turned back,
        swipe / drag handled in Row.jsx. The remote follows the screen: Left goes further into a row.
        Sitemaps list every page in every language (?lng=) with its hreflang alternates, 1,000 pages
        per file, so Google finds and pairs the translated pages without waiting to crawl them.
